# Optional model file

The large Gemma 3 1B IT Q4_K_M GGUF model is not included in this repository. For a build that packages the model, obtain the compatible file from an authorized Unsloth release and place it here as `gemma-3-1b-it.Q4_K_M.gguf`.

The model runs locally and does not rely on cloud quotas. Review and comply with the Gemma Terms of Use and the model distributor's terms before downloading, using, or redistributing it. The model's terms are separate from the GPL-3.0-only license for this project's source code.
